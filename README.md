# BreeHite.com

Static GitHub Pages site for Bree Hite's horseback adventures.

## Photo policy

Only verified photos containing at least one horse belong in `photos.json`. Do not add non-horse images.

Each entry uses:

```json
{"src":"assets/horses/photo.jpg","alt":"Description","caption":"Optional location or ride","date":"2026-10-01","source":"https://original-post-url","horse":true}
```

Images should be stored under `assets/horses/` whenever possible rather than hotlinked from social networks.
